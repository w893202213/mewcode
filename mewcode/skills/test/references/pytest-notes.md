# pytest 排查要点

本文件是 test 技能的参考文档（目录型技能的资源文件示例）。

## 常用命令

- `pytest tests/test_x.py -q` — 单文件跑
- `pytest tests/test_x.py::test_case -q` — 单用例跑
- `pytest tests/ -x -q` — 遇首个失败即停

## 排查顺序

1. 先读失败输出里的 assert 差异与 traceback 顶部（最里层出错点）
2. 再读失败用例源码，确认「预期行为」写的是什么
3. 最后读被测代码，定位行为偏差在哪个分支
4. 修复后先跑单用例，再跑相关文件，最后全量

## 常见坑

- 改测试还是改实现：先确认预期行为本身是否正确，不盲目改断言
- 中文编码：读写文件统一 UTF-8
- 时间/随机数：断言不要依赖非确定性输出
