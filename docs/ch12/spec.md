# ch12 斜杠命令系统 Spec

## 背景

现状（ch11 后）：斜杠命令是 `tui/commands.py` 里的硬编码 if-elif 链——命令名列表（`COMMAND_NAMES`）、处理逻辑（`handle_command`）、帮助文本（`_HELP_TEXT`）三处手工维护；补全是静态 `NestedCompleter`。每加一条命令要改多处，别名、大小写不敏感、隐藏命令等能力都不存在；处理函数直接持有 Console/session/Agent，与渲染框架强耦合；`/resume` 多步交互靠主循环特殊拦截，与其余命令不在同一分发路径上。

目标：建立「命令注册中心 + 斜杠解析器 + 回车入口分流器」的统一命令管道。斜杠输入绕过 Agent 直接本地执行——常用操作响应快、省 Token、行为确定，不让 LLM 处理清屏、查状态这类非对话杂事；命令实现只依赖界面控制接口，不绑定渲染框架；模式切换联动状态栏标记。

## 功能需求

### F1 命令注册中心

- 每条命令登记元数据：名称、别名、简短描述、用法示例、类型（本地 / 界面 / 提示词）、参数提示（可选）、是否隐藏（可选，默认否）、处理函数。
- 注册中心提供：登记、按名称查找（含别名解析）、可见命令列表（补全与帮助的数据源）。
- 构建完成时整体校验：命令名与别名之间任何重复（两条命令同名、一条命令的别名撞另一条的命令名或别名）都视为冲突，启动阶段即失败退出，stderr 输出冲突详情，不进入 TUI；命令名合法性校验（非空、非纯空白）。
- 现有 12 条命令全部迁移到注册中心：`/help`、`/compact`、`/clear`、`/plan`、`/do`、`/session`、`/memory`、`/permission`、`/status`、`/review`、`/exit`、`/resume`；`/mode` 是 `/permission` 的别名。

### F2 斜杠解析器

- 输入以 `/` 开头才进入命令路径；第一个空白字符前是命令名、之后是参数（参数保留原样，包括多余空格）。
- 命令名大小写不敏感：`/Help`、`/HELP` 与 `/help` 等价，统一按小写查找。
- 空输入、无斜杠输入不进入命令路径，快速返回。
- 未命中：提示「未知命令」，并引导输入 `/help` 查看可用命令。

### F3 三类执行模式

- **本地类**：只读计算与展示，不修改会话或界面状态（`/help`、`/status`、`/session`、`/memory`）。
- **界面类**：修改会话 / 模式 / 界面状态（`/clear`、`/plan`、`/do`、`/compact`、`/permission`、`/exit`、`/resume`）。
- **提示词类**：把预设提示词作为用户消息送入对话，交给 AI 处理（`/review`）。
- 类型是元数据标记，分发时统一走处理函数，类型决定行为语义（并为后续命令级权限留钩子）。

### F4 界面控制接口

- 命令处理函数不直接持有 Console / session / Agent，只依赖一个界面控制接口：
  1. 显示消息（展示反馈文本 / 面板）
  2. 发送用户消息（提示词类命令：注入对话并触发 Agent 一轮）
  3. 切换模式（计划模式开 / 关、权限档循环），并联动刷新状态栏
  4. 查询 Token（最近一轮与累计用量、上下文占用估算）
  5. 多步交互（读入用户输入、列表选择，供 `/resume` 使用）
- TUI 提供该接口的实现，处理函数经接口完成全部界面副作用；命令实现不依赖具体渲染框架。
- 状态栏持续显示权限档英文标记 `[STRICT]`/`[DEFAULT]`/`[ACCEPT]`，计划模式开启时追加 `[PLAN]`（如 `[DEFAULT][PLAN]`）；任一模式切换后状态栏立即刷新。

### F5 回车入口分流器

- 用户回车输入统一先过分流器：斜杠命令走本地分发，非命令送 Agent Loop。
- `/resume` 的多步交互纳入命令分发路径，不再由主循环单独拦截。
- 分发执行完成后回到输入循环。

### F6 别名与 Tab 补全

- 别名与原命令完全等价：解析层统一解析到主命令，处理函数不感知调用名。
- 补全基于注册中心的可见命令（隐藏命令不参与）与别名：输入前缀匹配时，单匹配直接补全（统一补主命令名）、多匹配弹菜单。
- `/help` 从注册中心动态生成：无参数列出全部可见命令（含别名展示）；`/help <命令>` 显示单条命令详情（描述、用法、别名）。

### F7 内置命令行为

- `/help`：列出全部可见命令；`/help <命令>` 单条详情。
- `/compact`：同现状，立即执行上下文压缩。
- `/clear`：同现状，清空对话上下文。
- `/plan`、`/do`：同现状，进入 / 退出计划模式，联动状态栏。
- `/permission`：无参数循环切换权限档并显示新档位；`show` 子参数展示当前档位 + 已登记规则（会话级 / 永久级）；`/mode` 为其别名。
- `/status`：配置名、模型、思考模式、权限档、计划模式、token 用量（最近一轮输入 / 输出 / 缓存命中与写入，会话累计）、上下文占用估算（消息数 / 估算 token 对窗口上限）。
- `/session`：当前会话 ID、标题、消息数、存档路径、最后活动时间；记忆系统未启用时显示「纯内存会话（无存档）」。
- `/memory`：三层指令文件加载状态、笔记数（项目 / 用户）、会话存档数；记忆系统未启用时提示不可用。
- `/review`：注入预设提示词到对话——请用 run_command 执行 git diff 查看当前项目改动，审查其中的 bug、风险与可改进点。
- `/exit`：退出 MewCode。
- `/resume`：同现状多步交互（列出最近会话 → 选编号 → 恢复）。

## 非功能需求

- N1 行为确定性：斜杠命令执行不消耗模型调用（提示词类除外），响应即时、结果固定。
- N2 可扩展：新增一条命令 = 注册元数据 + 写一个处理函数，`/help` 与补全自动生效，无其他改动点。
- N3 解耦：命令实现不依赖具体渲染框架（Rich / prompt_toolkit），仅依赖界面控制接口。
- N4 可测试：注册中心、解析器、补全匹配逻辑可脱离 TUI 独立单测。
- N5 兼容：既有命令输入行为不回归（ch07 `/mode` 循环切换、ch09 `/compact`、ch11 `/resume` 的既有验收保持通过）。

## 不做的事

- 用户自定义命令（留给 Skill 系统）
- 动态生成提示词（模板参数化留后续）
- 命令级权限控制
- 命令参数 schema 校验（参数提示仅展示用，不做解析校验）
- 多级子命令层级（仅支持 `/permission show`、`/help <命令>` 这类单层参数）

## 验收标准

- AC1（F1）: 构造两条同名 / 别名撞车的命令注册 → 启动失败退出，stderr 输出冲突详情。
- AC2（F2）: `/HELP` 与 `/help` 行为一致；输入 `/help  abc` 时参数为 ` abc`（去掉首个分隔空白，其余多余空格原样保留）。
- AC3（F2）: 输入 `/nope` → 输出未知命令提示，且包含 `/help` 引导。
- AC4（F3）: 输入 `/review` → Agent 收到预设审查提示词并开始一轮回复，本地无其他副作用。
- AC5（F4）: 状态栏默认显示 `[DEFAULT]`；`/plan` 后变 `[DEFAULT][PLAN]`；`/do` 后恢复 `[DEFAULT]`；`/permission` 切换后档位标记同步刷新。
- AC6（F5）: 输入 `/status` → 立即显示状态，期间不发起任何模型请求。
- AC7（F6）: 输入 `/cl` 按 Tab 直接补全 `/clear`；输入 `/c` 按 Tab 弹菜单（含 `/clear`、`/compact`）；输入 `/mo` 按 Tab 补出 `/permission`（别名解析到主名）。
- AC8（F7）: 12 条命令逐条执行，行为与 F7 描述一致。
- AC9（N5）: ch07 / ch09 / ch11 验收场景不回退（权限循环切换、压缩、会话恢复）。
